# Notice and attribution

**Driving Pressure** is built on **[Open Vent Sim](https://github.com/fedebarra/open-vent-sim)** by
Federico Lorenzo Barra (ARTID, Università del Piemonte Orientale), starting from upstream commit `0fbb16c`.
Open Vent Sim is released under the MIT licence, and its copyright notice is kept in [`LICENSE`](LICENSE).
Upstream attribution strings in the code are preserved.

If you use the original simulator in teaching or research, please cite the upstream paper:
Barra F. L. *et al.*, "Simulator development using natural language: clinician-led innovation through
artificial intelligence", *Advances in Simulation* (2026), https://doi.org/10.1186/s41077-026-00467-2.

The upstream project is an anaesthesia and ventilation simulator. This repository refocuses it on adult
ICU respiratory support and adds a new physiology engine, clinical cases, a learner model and the
active-learning layer described in the README. The upstream author has not reviewed or endorsed these
changes.
